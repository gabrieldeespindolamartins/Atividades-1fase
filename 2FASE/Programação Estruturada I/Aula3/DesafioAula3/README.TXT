TÍTULO DO PROJETO: Desafio Aula 03 - Comandos de Entrada/Saída e Associação entre Classes

OBJETIVO DO PROJETO: Praticar comandos de saída (System.out) e entrada de dados
(Classe Teclado e Scanner) dentro de classes de teste (main), reforçando o uso
de classes de teste para criação de objetos (Situação Computador e Situação
Cofrinho) e associação entre classes (Sistema de Aluguel de Imóveis: Cliente,
Imovel e Aluguel).

VERSÃO ou DATA: 2026-09-04

COMO INICIAR O PROJETO: Abrir a pasta no BlueJ (ou compilar via linha de
comando com javac *.java). Executar o método main da classe desejada:
- PrimeiraClasseDeTeste / ExemploFormato / ExemploEntradaParqueDiversao /
  ExemploScanner (Parte 01 - Entrada e Saída de dados)
- CriaComputador (Parte 02 - Situação Computador)
- TesteCofrinho (Parte 03 - Situação Cofrinho)
- Main (Parte 04 - Desafio Sistema de Aluguel de Imóveis)

AUTORES: Gabriel

INSTRUÇÕES PARA O USUÁRIO: Ao executar as classes que utilizam a Classe
Teclado ou Scanner (ExemploEntradaParqueDiversao, ExemploScanner,
TesteCofrinho, Main), digite os dados solicitados no console conforme as
mensagens exibidas.

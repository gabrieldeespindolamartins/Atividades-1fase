TÍTULO DO PROJETO: EstruturasDeSelecao (Aula 5 - IF / Switch-Case)

OBJETIVO DO PROJETO: Praticar as estruturas de seleção IF/ELSE e SWITCH/CASE
em Java, tanto diretamente no método main quanto aplicadas dentro de métodos,
conforme os exercícios 1 a 12 da lista da Aula 5. Toda a entrada de dados é
feita pelo teclado, usando a classe Teclado.

VERSÃO ou DATA: 2026-09-13

COMO INICIAR O PROJETO: Abrir esta pasta no BlueJ (arquivo package.bluej) ou
compilar pela linha de comando com "javac -encoding UTF-8 *.java" e executar
"java NomeDaClasse".

CLASSES DE EXERCÍCIO (lista de tarefas - pdf 02):
- Teste01: itens a) a f) - if simples, if/else, ifs aninhados e método que
  classifica a média (Otimo / Bom / Aprovado / Em recuperação)
- Teste02: troca de valores entre a, b e c; imprime quais if's executam e
  traz nas RESPOSTAS as situações i, ii, iii e iv
- Teste03: operadores e expressões booleanas; as RESPOSTAS a), b) e c) estão
  em comentários no final da classe
- Teste04: if/else aninhado (C1 a C6) com as RESPOSTAS das situações i a iv
- Teste05: cascata if / else if (C1 a C6) com as RESPOSTAS das situações
  v a viii
- Teste06: turno do dia (M/T/N, maiúscula ou minúscula) com else if
- Teste07: método que informa se o número é Positivo, Negativo ou Zero
- Teste08: método que retorna o menor de três números
- Teste09: método que retorna a categoria do atleta por idade e peso
- Teste10: método que recebe dois objetos Pessoa e retorna o nome do mais
  velho (ou "Mesma idade")
- Teste11: menu de operações com switch/case (adição, subtração,
  multiplicação e divisão)
- Teste12: método que recebe 3 notas por parâmetro, calcula a média e exibe
  o conceito (A a E)

EXEMPLOS DA AULA (pdf 01) com entrada de dados pelo teclado:
- VerificarIdade_if_else: classifica a faixa etária a partir da idade (IF)
- DiaDaSemanaSwitchCase: informa o dia da semana a partir de um número (SWITCH)
- CalcularPreco_IF_SwitchCase: calcula o preço do ingresso combinando IF
  (categoria pela idade) e SWITCH (preço pela categoria)

CLASSES AUXILIARES:
- Teclado: leitura de dados do teclado (leInt, leDouble, leString, leChar)
- Pessoa: classe com nome e idade, usada pelo Teste10

INSTRUÇÕES PARA O USUÁRIO: Ao executar qualquer classe, digite no console os
dados solicitados conforme as mensagens exibidas. Nos Teste02, Teste04 e
Teste05 digite pares de valores iguais para gerar true e valores diferentes
para gerar false nas variáveis booleanas.

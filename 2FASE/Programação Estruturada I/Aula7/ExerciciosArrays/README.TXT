TÍTULO DO PROJETO: ExerciciosArrays (Aula 7 - Arrays Unidimensionais e
Bidimensionais)

OBJETIVO DO PROJETO: Resolver os exercícios do pdf "03- ExerciciosArrays",
praticando declaração, instanciação, leitura e percurso de arrays
unidimensionais (vetores) e bidimensionais (matrizes) em Java.

VERSÃO ou DATA: 2026-09-27

COMO INICIAR O PROJETO: Abrir esta pasta no BlueJ (arquivo package.bluej) ou
compilar pela linha de comando com "javac -encoding UTF-8 *.java" e executar
"java NomeDaClasse".

CLASSES:
- Questao01: array a de inteiros já inicializado; responde os itens a) até
  l) sobre índices, conteúdo e a.length, e troca o elemento de índice 1 pelo
  valor digitado no teclado
- Questao02: declaração (vet nulo antes de instanciar), instanciação de um
  array de 15 inteiros, vet.length, último elemento e criação do array
  medias com 20 posições
- Questao03: preenche um array v com os números ímpares a partir de 1 e lê
  um array notas pelo teclado, validando o intervalo [0.0, 10.0] com
  do...while dentro do for
- Questao04: métodos calculaMedia (média aritmética de um array de
  inteiros) e contaMultiplos (quantidade de múltiplos comuns de 3 e 5)
- Questao05: matriz mat de inteiros já inicializada; responde os itens a)
  até l) sobre linhas, colunas, índices e mat.length
- Questao06: declaração e instanciação de uma matriz de inteiros (6x4) e
  declaração de matrizes de double e de char
- Questao07: métodos armazenaImpares (preenche uma matriz com números
  ímpares a partir de 1) e armazenaAleatorios (preenche uma matriz com
  números aleatórios no intervalo [10, 51))
- Questao08: métodos calculaMedia (média aritmética dos números da matriz)
  e contaMultiplos (quantidade de múltiplos comuns de 3 e 5 na matriz)

CLASSES AUXILIARES:
- Teclado: leitura de dados do teclado (leInt, leDouble, leString, leChar)

AUTORES: Gabriel

INSTRUÇÕES PARA O USUÁRIO: Ao executar Questao01 ou Questao03, digite no
console os dados solicitados conforme as mensagens exibidas. As demais
classes (Questao02, Questao04 a Questao08) já trazem os dados necessários
inicializados no código e não pedem entrada pelo teclado.

TÍTULO DO PROJETO: Estruturas de Seleção (IF / Switch-Case)

OBJETIVO DO PROJETO: Praticar as estruturas de seleção IF/ELSE e SWITCH/CASE
em Java, tanto isoladamente na classe main quanto aplicadas dentro de
métodos, conforme os exercícios propostos.

VERSÃO ou DATA: 2026-09-04

COMO INICIAR O PROJETO: Abrir a pasta no BlueJ (ou compilar via linha de
comando com javac *.java). Executar o método main de cada classe:
- Teste01 a Teste12: exercícios 1 a 12 da lista de tarefas (if/else,
  cascata de ifs, switch/case, métodos com seleção)
- Pessoa: classe auxiliar usada pelo Teste10
- VerificarIdade_if_else: classifica a faixa etária a partir da idade (IF)
- DiaDaSemanaSwitchCase: informa o dia da semana a partir de um número (SWITCH)
- CalcularPreco_IF_SwitchCase: calcula o preço de um ingresso combinando
  IF (categoria por idade) e SWITCH (preço por categoria)

AUTORES: Gabriel

INSTRUÇÕES PARA O USUÁRIO: Ao executar qualquer uma das classes, digite os
dados solicitados no console conforme as mensagens exibidas (usa a Classe
Teclado para entrada de dados).
